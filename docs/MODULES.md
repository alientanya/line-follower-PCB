# Hardware Module Documentation

This document provides a detailed breakdown of the functional modules, power circuits, controller revisions, and interchangeable sensor arrays used in the **FLF Bot Modular PCB** platform.

---

## 2. Power Management Module

The power distribution system is designed to isolate sensitive digital controller logic from high-current motor inductive noise.

- **Primary Voltage Regulator**: MP1584 Step-Down (Buck) DC-DC Converter.
  - **Input Voltage**: 2S / 3S LiPo battery (7.4V – 11.1V nominal).
  - **Output Voltage**: Clean 3.3V rail powering the STM32 MCU, 74HC4067 MUX, sensors, and HC-05 module.
  - **Efficiency**: High efficiency reduces heat generation during long runs.
- **Power Rail & Ground Isolation**: Logic supply (3.3V) and motor supply (VCC/VM) run on isolated power traces with dedicated bulk decoupling capacitors (electrolytic + ceramic) across motor supply lines to absorb inductive back-EMF spikes.
- **Dual Safety Kill Switches**:
  - **Battery Kill Switch**: Completely isolates the LiPo battery from the entire board.
  - **Motor Kill Switch**: Cuts power exclusively to the TB6612FNG motor driver `VM` rail while keeping MCU logic and Bluetooth active for telemetry and calibration.

## 3. Microcontroller Module & Debug Interface

### Lavender 1.0 (Blackpill Breakout) — *Field Tested*
- **MCU Core**: STM32F411CEU6 (ARM Cortex-M4 @ 100MHz, 512KB Flash, 128KB SRAM).
- **Form Factor**: Plug-in daughterboard headers.
- **Advantages**:
  - Modular replacement in case of overvoltage or pin damage during field testing.
  - Integrated USB-C port for rapid DFU/ST-Link flashing.
  - Onboard 25MHz HSE crystal and 32.768kHz LSE crystal.

### Lavender 2.0 (Discrete IC) — *Work In Progress*
- **MCU Core**: Surface-mount STM32F411 IC directly soldered to the main PCB (`STMf411.kicad_sch`).
- **Features**: Dedicated SWD (Serial Wire Debug) header, external HSE crystal circuit, decoupling capacitor network, and boot mode configuration resistors.

### SWD Debug & Programming Header
- Breakout header (`SWDIO`, `SWCLK`, `GND`, `3.3V`) providing direct in-circuit programming and live step-debugging via ST-Link V2/V3 hardware debuggers.

---

## 4. Motor Driver Module

- **IC**: Toshiba TB6612FNG Dual H-Bridge Driver.
- **Application**: Controls two micro N20 DC gearmotors (Left Motor & Right Motor).
- **Interfaces**:
  - **PWM Pins (PWMA, PWMB)**: Connected to STM32 hardware timer outputs for precise motor speed control.
  - **Direction Pins (AIN1/2, BIN1/2)**: GPIO lines controlling forward, reverse, and braking modes.
  - **Standby (STBY)**: Tied to MCU GPIO for emergency driver shutdown.
- **Protection**: Onboard decoupling capacitors to absorb voltage spikes and back-EMF generated by the motors.

---

## 5. Analog Signal Multiplexing

- **IC**: Texas Instruments 74HC4067 (16-Channel Analog Multiplexer / Demultiplexer).
- **Role**: Expands the MCU's analog sensing capability for high-density sensor arrays without consuming 16 separate ADC pins.
- **Control Interface**:
  - **Select Lines (S0, S1, S2, S3)**: 4 digital outputs from the STM32 select one of the 16 channels.
  - **Enable Line (EN)**: Active-low enable pin connected to ground/MCU GPIO.
  - **Signal Line (SIG)**: Common multiplexed analog output fed directly into an STM32 ADC channel.

## 6. Interchangeable Sensor Array Modules

All sensor arrays connect to the main body PCB via a standardized header interface (`layerconnect.kicad_sch`).

### 1. 16-Sensor Curved Array (QRE1113 + 74HC4067 MUX)
- **Sensor IC**: 16x QRE1113 miniature reflective IR phototransistors.
- **Topology**: Curved geometry following line entry angles.
- **Routing**: Routed through 74HC4067 MUX → single MCU ADC channel.
- **Best Use Case**: High-resolution line tracking for sharp turns and complex curves.

### 2. 9-Sensor Straight Array (QRE1113)
- **Sensor IC**: 9x QRE1113 optical sensors.
- **Topology**: Straight linear arrangement.
- **Routing**: Direct pin mapping to 9 dedicated STM32 ADC channels.
- **Best Use Case**: Minimum latency sampling and fast straight-line acceleration.

### 3. 9-Sensor Curved Array (TCRT5000)
- **Sensor IC**: 9x TCRT5000 reflective optical sensors.
- **Topology**: Slightly curved front layout.
- **Characteristics**: Wider sensing distance tolerance, ideal for non-uniform track surfaces.

### 4. Custom Discrete Sensor Array
- **Components**: Discrete IR Emitters (LEDs) + PT334-6C Phototransistors.
- **Features**: Individual bias resistors and tuning load resistor networks for custom sensitivity calibration.

---

## 7. Emitter Biasing & Phototransistor Load Networks

- **IR Emitter Current Limiting**: Series resistor arrays calculated to supply optimal forward current to IR LEDs without exceeding power limits or overheating.
- **Phototransistor Load Resistors**: Precision pull-down load resistors converting phototransistor collector current into sharp, low-noise analog voltage levels for MCU ADC sampling.

---

## 8. 8+1 Sensor Placement Strategy

- **8 Main Sensors**: Form the primary array positioned along the front arc for continuous PID line-position estimation.
- **+1 Overshoot Sensor**: Placed further ahead at the front apex. Detects upcoming turn entries, sharp 90° corners, or line loss early, triggering pre-programmed braking or turn-entry algorithms before the main array loses tracking.

---

## 9. Wireless Telemetry, Debounced UI & Diagnostics

- **Bluetooth Module (HC-05)**:
  - Connected to STM32 USART port.
  - Used for real-time PID tuning, live sensor data streaming, and telemetry logging without tethering a cable.
  - Includes `STATE` and `EN` line breakouts for connection state monitoring.
- **Hardware-Debounced Tactile Switches**:
  - 2 user-configurable push buttons.
  - Dedicated **RC Low-Pass Filter Networks** (resistor + capacitor pairs) connected across button contacts to hardware-bounce-filter mechanical contacts before signals reach STM32 GPIO pins.
  - Used for sensor calibration, mode selection, or launching runs.
- **Visual Status LEDs**: Onboard diagnostic LEDs providing instant visual indication for 3.3V power availability and system execution states.

---

## 10. Inter-Board Header Bus & Mechanical Stacking

- **Layer Connection Header (`layerconnect.kicad_sch`)**: Multi-pin connector array bridging power (3.3V, GND), 16 analog MUX signals, and direct sensor lines between the main control PCB and sensor plates.
- **3D Stacked Frame Construction**: Standoff mounting holes (`H1`-`H12`) lock the main PCB and top plate into a rigid chassis, leaving a central cavity designed specifically to fit 2S/3S LiPo batteries while maintaining a low center of gravity.
